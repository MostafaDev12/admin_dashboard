# velzon-laravel-

The integrated Laravel website and Velzon CMS are documented in [the implementation and setup guide](docs/CMS_IMPLEMENTATION.md). See [the frontend content map](docs/FRONTEND_MAP.md) for every imported page, section, and collection.

Run the verified local installation with `./scripts/cms.ps1 serve`, then create an administrator using `./scripts/cms.ps1 website:admin your-email@example.com` (password entered interactively).
